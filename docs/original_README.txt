C++의 OpenGL 라이브러리를 활용해 3D 미로찾기와 모델링 구현 툴을 구현했습니다. 
bin 파일 내부에 들어가면 모델링 데이터와 exe 파일 두 개가 있습니다. 추가로 프로젝트 당시 작성한 보고서를 첨부하였습니다.

Final.exe : 게임 실행 파일입니다. wasd로 이동하며 마우스 좌클릭을 한 상태로 커서를 움직여 화면을 회전시킵니다. r키를 눌러 처음 위치로 돌아올 수 있습니다.
게임의 목표는 특정한 아이템 세 개를 모아 잠금된 구역을 해제해 그곳으로 가는 것입니다. 

SOR.exe : 게임 속에서 사용한 3차원 오브젝트를 모델링한 툴입니다. 회색 사분면 상에 좌클릭하여 빨간 점을 찍고 우클릭을 통해 다양한 기능을 실행시킬 수 있습니다. 
scale - 점 분포도 조절 / rotate - 360의 약수를 넣어 해당 각도만큼씩 회전된 점 생성 / connect - 연결 순서 연산 / make face - 점 연결

보고서 : 프로젝트 전반에 대한 내용을 작성한 보고서입니다. 미로의 전체적인 구조와 모델링을 어떻게 활용하였는지 제시되어 있습니다.
